# 월하검무

달빛 검사 리아가 밤마다 몰려오는 그림자 무리를 베어 내는 픽셀 액션 RPG입니다. 브라우저에서 바로 플레이할 수 있어요.

## 조작

| 키 | 동작 |
|---|---|
| ← → | 이동 |
| X · ↑ · Space | 점프 (공중에서 한 번 더) |
| Z | 베기, 연타하면 3연격 |
| C | 대시 (잠깐 무적) |
| V | 월광참 (MP 25) |

모바일에서는 화면 아래 버튼으로 조작합니다.

## 현재 구성 (프로토타입 01)

- 웨이브 진행, 4웨이브마다 보스(그림자 기사)
- 경험치와 레벨업, 치명타, 회복 하트 드랍
- 모든 그래픽은 코드로 그린 오리지널 픽셀아트
