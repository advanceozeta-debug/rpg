# 월하검무

달빛 아래 그림자 무리와 싸우는 픽셀 액션 RPG입니다. 브라우저에서 바로 플레이할 수 있어요.

**플레이:** https://advanceozeta-debug.github.io/rpg/

## 구성 (v0.2)

- **월하정 (거점)**: 걸어 다니며 시설을 이용해요.
  - 소환 제단: 월석으로 영웅 소환 (★3~★5, 12명, 천장 있음)
  - 편성: 출전·교대 영웅 지정
  - 영웅 육성: 레벨 업 · 한계돌파(최대 레벨 40→90) · 초월(3단계, 단계당 능력치 +15%) · 스킬 강화(Lv.10)
  - 영구 강화: 은화로 계정 전체 공격·체력·치명타·쿨타임·이동 속도·은화 획득 강화
  - 업적 비석: 업적 37개와 보상, 기록
  - 영웅록: 영웅 도감과 스킬 정보
  - 수련 허수아비: DPS 측정
  - 출정의 문: 스테이지 선택
- **스테이지**: 제1장 달빛 숲길, 제2장 안개 낀 폐사 (각 5스테이지, 마지막은 보스 월식수)
- **무한 회랑**: 끝없이 이어지는 웨이브, 최고 기록 저장
- **설정**: 음량, 화면 흔들림, 데미지 숫자, 터치 패드, 저장 데이터 내보내기/가져오기, 쿠폰

## 조작

| 키 | 동작 |
|---|---|
| A D / ← → | 이동 |
| W / Space / ↑ / K | 점프 (2단) |
| S + 점프 | 발판 아래로 |
| J / Z | 기본 공격 (연타 콤보) |
| Shift / L / C | 대시 (무적) |
| E / Q | 스킬 1 / 스킬 2 |
| G | 교대 |
| F | 상호작용 |
| Esc | 메뉴 |

모바일에서는 화면 아래 터치 패드로 조작합니다.

## 파일 구조

- `index.html` — 화면과 스타일
- `js/data.js` — 영웅, 스킬, 적, 스테이지 수치
- `js/art.js` — 모든 픽셀 아트 (코드로 그림)
- `js/world.js` — 전투·이동 엔진
- `js/hud.js` — 화면 위 정보
- `js/ui.js` — 메뉴 화면
- `js/audio.js` — 효과음·배경음 합성
- `js/save.js`, `js/input.js`, `js/main.js`

저장 데이터는 플레이하는 기기의 브라우저에 보관됩니다.
